== Setting Up a New Project

This chapter walks through creating a new documentation project
that inherits the full pipeline.

=== Prerequisites

* *Maven 4+* -- required by the reactor POM (uses `modelVersion 4.1.0`)
* *Java 25* -- the `ike-parent` Java toolchain target
* *Node.js 18+* -- optional, only needed for `svgo` (Prawn SVG fixing)

The Maven enforcer plugin validates these at build time with
clear error messages.

=== Step 1: Create the POM

Create a minimal `pom.xml` that inherits from the documentation
parent (or Java parent if you have source code):

[source,xml]
----
<?xml version="1.0" encoding="UTF-8"?>
<project xmlns="http://maven.apache.org/POM/4.1.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.1.0
         http://maven.apache.org/xsd/maven-4.1.0.xsd">
    <modelVersion>4.1.0</modelVersion>

    <parent>
        <groupId>network.ike.platform</groupId>
        <artifactId>ike-parent</artifactId>           <!--1-->
        <version>26</version>
        <relativePath/>
    </parent>

    <groupId>com.example</groupId>
    <artifactId>my-project</artifactId>
    <version>1.0.0-SNAPSHOT</version>

    <name>My Project</name>

    <dependencies>
        <dependency>
            <groupId>network.ike.docs</groupId>
            <artifactId>minimal-fonts</artifactId>    <!--2-->
            <type>zip</type>
        </dependency>
    </dependencies>

    <build>
        <plugins>
            <plugin>
                <groupId>org.asciidoctor</groupId>
                <artifactId>asciidoctor-maven-plugin</artifactId> <!--3-->
            </plugin>
        </plugins>
    </build>
</project>
----
<1> `ike-parent` covers both doc-only and Java-plus-docs (hybrid) projects; the post-`IKE-Network/ike-issues#216` topology consolidated the previously-distinct `java-parent` into `ike-parent`.
<2> Required for Prawn PDF font rendering; version managed by parent
<3> Declares the plugin so Maven runs it; all configuration inherited from parent

=== Step 2: Create the Index Document

Create `src/docs/asciidoc/index.adoc`:

[source,asciidoc]
----
= My Project Documentation
:author: IKE Network
:email: info@ike.network
:revnumber: {project-version}
:revdate: {docdate}
:doctype: book
:toc: left
:toclevels: 3
:sectnums:
:sectnumlevels: 4
:icons: font
:source-highlighter: coderay
:experimental:

== Introduction

Your content here.
----

=== Step 3 (workspace consumers): Add to a workspace

If your project lives inside an IKE workspace alongside other
subprojects, register it via:

[source,bash]
----
mvn ws:add -Drepo=git@github.com:your-org/my-project.git
----

`ws:add` clones the repository, derives the subproject name and
groupId from the cloned POM, and appends the subproject to the
workspace's `workspace.yaml` and reactor POM. Standalone projects
(not inside a workspace) skip this step entirely — Maven discovers
the project from its own `pom.xml`.

=== Step 4: Build

[source,bash]
----
# HTML only (default profile)
mvn clean verify -pl my-project

# Apache FOP PDF (recommended free renderer, pure Java)
mvn clean verify -pl my-project -Dike.pdf.fop

# WeasyPrint PDF (alternative free, requires Python)
mvn clean verify -pl my-project -Dike.pdf.weasyprint

# Prince XML PDF (commercial, best quality)
mvn clean verify -pl my-project -Dike.pdf.prince

# Prawn PDF (preview quality, no glossary)
mvn clean verify -pl my-project -Dike.pdf.prawn

# Full reactor build with FOP PDF
mvn clean verify -Dike.pdf.fop
----

=== Adding Chapters

Create chapter files in `src/docs/asciidoc/chapters/` and
include them from `index.adoc`:

[source,asciidoc]
----
\include::chapters/my-chapter.adoc[]
----

Each chapter file starts at the `==` heading level (the
`index.adoc` book structure provides the `=` level).

=== Adding Diagrams

Embed diagrams directly in AsciiDoc.
The Kroki server renders them at build time:

[source,asciidoc]
-----
[plantuml]
....
@startuml
A -> B : Build
B -> C : Output
@enduml
....
-----

No local diagram tools needed.
Kroki handles Mermaid,
PlantUML, GraphViz,
and 20+ other diagram types.

=== Cross-Module Includes

To include documentation from another module,
add a dependency with the `adoc` classifier:

[source,xml]
----
<dependency>
    <groupId>com.example</groupId>
    <artifactId>other-project</artifactId>
    <version>1.0.0-SNAPSHOT</version>
    <classifier>adoc</classifier>
    <type>zip</type>
</dependency>
----

Then include using the `{generated}` attribute:

[source,asciidoc]
----
\include::{generated}/other-project/chapters/shared-chapter.adoc[]
----

The `maven-dependency-plugin` unpacks these to
`target/generated-sources/asciidoc/`.
